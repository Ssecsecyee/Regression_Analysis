# Northern Sea Route SIC Regression Experiment

## 1. 연구 목적

본 프로젝트는 북극항로(Northern Sea Route, NSR)의 주요 항행 병목 지점에서 해빙 농도
(`Sea Ice Concentration`, 이하 `SIC`)를 회귀분석으로 예측하기 위한 실험이다. 전체 북극
격자를 한 번에 학습하기에는 로컬 장비 성능 제약이 있으므로, 우선 실제 항로 의사결정에
중요한 6개 요충지의 단일 격자 픽셀을 대상으로 독립적인 회귀모형을 구축한다.

회귀분석의 최종 출력값은 각 지점의 월별 `SIC` 농도이며, 입력 변수는 동일 지점에서 관측된
대기·해양 예측변수 6종이다.

본 실험은 다음 질문에 답하는 것을 목표로 한다.

- 북극항로 주요 병목 지점에서 월별 `SIC`를 국지적 대기·해양 변수만으로 어느 정도 설명할 수 있는가?
- 지점별로 `SIC` 예측 성능과 주요 설명변수의 영향이 어떻게 달라지는가?
- 전체 격자 학습 전에, 단일 픽셀 기반 회귀분석이 실험 설계와 변수 선택에 어떤 기준을 제공하는가?

## 2. 데이터 개요

사용 데이터는 NSIDC 해빙 농도와 ERA5 표면 예측변수를 북반구 극지 25 km 격자에 정렬한
NetCDF 자료이다. 모든 주요 변수는 동일한 공간 격자와 시간축을 사용한다.

### 2.1 공간 격자

- 격자 체계: NSIDC 북반구 극지 25 km 격자
- 좌표계: EPSG:3411
- 배열 크기: `448 x 304`
- 공간 해상도: `25 km x 25 km`
- 단일 픽셀 면적: 약 `625 km2`
- 축 방향: `y`는 south-first 방향으로 저장됨

전체 격자는 대략 `31.1N-89.8N`, `180W-179.8E` 범위를 포함한다. 본 실험의 실제 관심
영역은 월별 active sea-ice mask 내부에서 북극항로와 겹치는 해역이다.

### 2.2 시간 해상도

본 실험의 1차 분석은 월별 자료를 사용한다.

- 월별 기간: `1988-02`부터 `2025-12`까지
- 전체 월별 샘플 수: `455`
- 주별 자료도 존재하지만, 초기 실험에서는 로컬 장비 부담을 줄이기 위해 월별 자료를 우선 사용한다.

### 2.3 변수 구성

총 7개 변수를 사용한다.

| 변수 | 역할 | 설명 | 단위 |
|---|---|---|---|
| `sic` | 타깃 | 해빙 농도 | 1, 0-1 |
| `tos` | 입력 | 해수면 온도 | K |
| `tas` | 입력 | 2 m 기온 | K |
| `rlds` | 입력 | 하향 장파복사 | W m-2 |
| `rsds` | 입력 | 하향 단파복사 | W m-2 |
| `uas` | 입력 | 10 m 바람, 격자 동향 성분 | m s-1 |
| `vas` | 입력 | 10 m 바람, 격자 북향 성분 | m s-1 |

회귀분석에서는 같은 시점의 `sic`를 입력에 포함하지 않는다. 동일 시점의 `sic`를 입력으로
넣으면 정답 누수가 발생하기 때문이다. 필요할 경우 후속 실험에서 이전 시점의
`sic(t-1)`를 별도 자기회귀 입력으로 추가할 수 있다.

## 4. 주요 입력 파일의 목적

### 4.1 월별 NetCDF 파일

`data/monthly` 폴더의 NetCDF 파일은 본 실험의 주 분석 자료이다. 각 파일은 변수 하나를
담고 있으며, 공통적으로 `(time, y, x)` 구조를 가진다.

예를 들어 `sic_arctic25km_monthly_1988-2025.nc`의 주요 구조는 다음과 같다.

- `sic`: 월별 해빙 농도, shape = `(455, 448, 304)`
- `time`: 월별 시간축
- `year`: 연도
- `month`: 월
- `y`, `x`: 극지 투영 좌표, 단위 m
- `lat`, `lon`: 각 격자 셀의 위경도

회귀분석에서는 각 후보 지점의 `(y_idx, x_idx)`를 고정한 뒤, 시간축 방향으로 값을 추출한다.

### 4.2 마스크 파일

`data/masks/active_mask.nc`는 월별 active sea-ice mask를 제공한다. `active_01`부터
`active_12`까지 월별 마스크가 포함되어 있으며, 해당 월에 해빙이 출현할 수 있는 분석
대상 영역을 나타낸다.

`data/masks/land_mask.nc`는 육지, 해양, 해안선 및 좌표 정보를 제공한다. 시각화에서는
육지 영역과 해양 영역을 구분하기 위해 사용한다.

### 4.3 정규화 통계 파일

`norm_stats_monthly.json`과 `norm_stats_weekly.json`은 각 변수의 평균, 표준편차, 최솟값,
최댓값을 담고 있다. 현재 1차 회귀분석에서는 단일 픽셀 시계열을 대상으로 하므로,
모델별 전처리 방식에 따라 다음 두 방법 중 하나를 사용할 수 있다.

- 전체 데이터 제공 통계를 사용하여 변수별 정규화
- train 구간에서 후보 픽셀 기준으로 평균과 표준편차를 다시 계산

논문식 실험 재현성을 위해서는 두 번째 방법, 즉 train 구간에서만 정규화 통계를 계산하는
방식이 더 안전하다.

북극항로 주요 후보 지점을 active sea-ice mask 위에 표시하는 시각화 스크립트이다. 현재
7월부터 10월까지의 월별 active mask를 원 데이터의 극지 투영 좌표 `x (m)`, `y (m)` 기준으로

- 지점들이 북극항로 병목 구간에 해당하는지 시각적으로 검토
- 향후 회귀분석 대상 픽셀을 명확히 문서화

### 5.2 `nsr_bottlenecks_jul_oct.png`

`plot_nsr_bottlenecks.py`를 실행하여 생성한 그림 파일이다. 7월, 8월, 9월, 10월 active

- 청록색: active sea-ice mask
- 진한 보라색: ocean / non-active 영역

- 노란 원: 회귀분석 후보 지점

## 6. 회귀분석 대상 지점

분석 대상은 북극항로에서 항행 가능성 판단에 중요한 6개 요충지이다. 각 지점은 원 데이터
격자에서 단일 픽셀로 정의한다.

| 번호 | 지점 | 격자 인덱스 `(y, x)` | 마스크 내부 위경도 | 해석 |
|---:|---|---:|---:|---|
| 1 | Vilkitsky Strait | `(259, 183)` | `77.5332N, 102.0426E` | Kara Sea에서 Laptev Sea로 넘어가는 핵심 관문 |
| 2 | NW Laptev Sea | `(262, 171)` | `78.1418N, 115.1593E` | 북서 Laptev Sea의 주요 해빙 병목 |
| 3 | Sannikov Strait | `(281, 150)` | `74.4931N, 137.9682E` | New Siberian Islands 부근 통과 후보 |
| 4 | Dmitry Laptev Strait | `(286, 146)` | `73.2940N, 140.9061E` | 얕고 좁은 남쪽 통로 |
| 5 | Central East Siberian Sea | `(273, 126)` | `74.9566N, 159.8057E` | East Siberian Sea 중앙 해빙 장벽 |
| 6 | Long Strait / Wrangel | `(277, 94)` | `70.1118N, 178.1374E` | Wrangel Island 부근 동쪽 출구 병목 |

각 지점은 원본 격자의 단일 셀이다. 따라서 월별 회귀분석에서 한 지점의 타깃 시계열은
다음과 같이 표현된다.

```text
sic[:, y_idx, x_idx]
```

예를 들어 2번 지점인 `NW Laptev Sea`의 월별 타깃은 다음과 같다.

```text
sic[:, 262, 171]
```

## 7. 실험 설계

### 7.1 기본 실험 단위

각 후보 지점에 대해 독립적인 회귀모형을 학습한다.

```text
Point 1 model: X_1 -> SIC_1
Point 2 model: X_2 -> SIC_2
...
Point 6 model: X_6 -> SIC_6
```

각 지점에서 하나의 월은 하나의 표본이 된다. 월별 전체 기간을 사용하면 지점당 최대
455개의 표본을 사용할 수 있다.

### 7.2 입력 변수와 출력 변수

기본 입력 변수는 다음 6개이다.

```text
X = [tos, tas, rlds, rsds, uas, vas]
```

출력 변수는 동일 지점의 `SIC`이다.

```text
y = sic
```

각 지점의 표본 행은 개념적으로 다음과 같다.

```text
time, point_id, tos, tas, rlds, rsds, uas, vas, sic
1988-02, 1, ..., ..., ..., ..., ..., ..., ...
1988-03, 1, ..., ..., ..., ..., ..., ..., ...
...
2025-12, 1, ..., ..., ..., ..., ..., ..., ...
```

### 7.3 사용 월

본 실험은 1월부터 12월까지 전체 월을 사용한다. 특정 항행철인 7월-10월만 사용할 수도
있지만, 초기 회귀분석에서는 전체 계절성을 포함하는 것이 표본 수 확보와 계절 변화 학습에
유리하다.

후속 실험에서는 다음과 같은 비교가 가능하다.

- 전체 월 사용 모델
- 7월-10월만 사용한 항행철 모델
- 월 정보를 범주형 또는 주기형 변수로 추가한 모델

### 7.4 학습, 검증, 테스트 분리

시간자료이므로 무작위 분할을 사용하지 않는다. 과거 자료로 학습하고 미래 자료에서 평가하는
방식을 사용한다.

| 구분 | 기간 | 월별 샘플 수 |
|---|---|---:|
| train | `1988-02` - `2013-12` | 311 |
| validation | `2014-01` - `2017-12` | 48 |
| test | `2018-01` - `2025-12` | 96 |
| total | `1988-02` - `2025-12` | 455 |

train 구간은 모델 학습과 정규화 통계 계산에만 사용한다. validation 구간은 모델 선택,
하이퍼파라미터 조정, 변수 선택에 사용한다. test 구간은 최종 성능 평가에만 사용한다.

## 8. 결측값 처리 원칙

NetCDF 파일의 결측값은 `_FillValue`로 저장되어 있으며, 실제 분석에서는 `NaN`으로 변환하여
처리해야 한다. 모든 입력 변수와 타깃 `sic`가 유효한 시점만 회귀분석에 사용한다.

특히 `tos`는 일부 해빙 영역에서 결측이 존재할 수 있다. 현재 후보 지점 중 4번
`Dmitry Laptev Strait`는 `tos_valid=0`으로 확인되었다. 따라서 4번 지점은 다음 처리 중
하나가 필요하다.

- 결측 시점을 제거하고 6개 입력 변수 모델을 학습
- `tos`를 제외한 5개 입력 변수 모델을 별도 학습
- 가장 가까운 `tos_valid=1` 주변 픽셀로 후보 지점을 조정

초기 비교에서는 모든 지점에 대해 결측 제거 후 학습을 수행하고, 4번 지점의 표본 수 감소를
결과 표에 명시한다. 만약 4번 지점에서 `tos` 결측으로 표본 수가 지나치게 줄어들면, 4번은
`tos` 제외 모델을 병행한다.

## 9. 모델 후보

초기 실험은 해석 가능성과 재현성을 우선한다.

### 9.1 Linear Regression

가장 기본적인 선형 회귀모형이다. 각 변수의 계수를 통해 `SIC`와 입력 변수 사이의 선형 관계를
해석할 수 있다.

### 9.2 Ridge Regression

변수 간 상관성이 강할 때 계수 폭주를 완화하기 위한 L2 정규화 선형모형이다. 기온, 해수면
온도, 복사 변수 사이에는 계절성이 공유되므로 Ridge 회귀가 기본 선형회귀보다 안정적일 수
있다.

### 9.3 Random Forest Regression

비선형 관계와 변수 간 상호작용을 포착하기 위한 비교 모델이다. 단일 픽셀 기준 표본 수가
455개로 많지 않으므로, 과적합 여부를 validation/test 성능 차이로 반드시 확인한다.

## 10. 평가 지표

각 지점별 test 성능은 다음 지표로 평가한다.

| 지표 | 목적 |
|---|---|
| RMSE | 큰 오차에 민감한 평균 예측 오차 |
| MAE | 해석이 쉬운 평균 절대 오차 |
| R2 | 입력 변수들이 `SIC` 변동을 설명하는 비율 |
| Bias | 예측값이 체계적으로 과대 또는 과소인지 확인 |

필요하면 `SIC >= 0.15` 기준의 이진 해빙 존재 여부도 계산할 수 있다.

```text
ice_present = sic >= 0.15
```

이 기준은 해빙 면적 및 항행 가능성 분석에서 자주 사용되는 임계값이다.

## 12. 후속 확장 계획

단일 픽셀 회귀분석이 완료되면 다음 단계로 확장할 수 있다.

1. 각 지점 주변 `3 x 3` 픽셀 평균을 타깃으로 사용
2. 각 지점 주변 `5 x 5` 픽셀 평균을 타깃으로 사용
3. 이전 월 `sic(t-1)`를 입력 변수로 추가
4. `month`를 계절성 변수로 추가
5. 월별 모델과 7월-10월 항행철 전용 모델 비교
6. 주별 자료로 확장하여 더 촘촘한 시간해상도 실험 수행

## 13. 현재 결정 사항 요약

- 초기 실험은 월별 자료를 사용한다.
- 분석 기간은 1월부터 12월까지 전체 월이다.
- 총 6개 북극항로 후보 지점을 사용한다.
- 각 후보 지점은 단일 25 km 픽셀이다.
- 타깃은 각 픽셀의 월별 `SIC`이다.
- 입력 변수는 `tos`, `tas`, `rlds`, `rsds`, `uas`, `vas`이다.
- train/validation/test는 시간 순서대로 분리한다.
- 무작위 분할은 사용하지 않는다.
- 4번 지점은 `tos` 결측 가능성을 별도로 관리한다.
